# Phòng thí nghiệm sắc kí sắc tố lá cây

Website giáo dục tương tác chạy thuần HTML, CSS và JavaScript, không cần framework hay cài thư viện.

## Tính năng
- Mô phỏng sắc kí giấy có tiến trình và điều chỉnh tốc độ.
- Bắt đầu, tạm dừng, làm lại và xem nhanh kết quả.
- Chọn sắc tố để làm nổi bật dải màu.
- Giải thích quy trình và hệ số Rf.
- Bộ 6 câu hỏi trắc nghiệm có phản hồi, chấm điểm và chơi lại.
- Thiết kế responsive cho điện thoại và máy tính.

## Chạy thử
Mở `index.html` bằng trình duyệt.

## Đưa lên GitHub Pages
1. Tạo một repository GitHub mới.
2. Tải `index.html` lên thư mục gốc của repository.
3. Mở **Settings → Pages**.
4. Ở phần **Build and deployment**, chọn **Deploy from a branch**.
5. Chọn branch `main`, folder `/ (root)`, rồi nhấn **Save**.
6. Đợi GitHub xuất bản trang và mở URL được cung cấp ở mục Pages.

Website này không cần backend. Điểm quiz chỉ lưu trong bộ nhớ của phiên hiện tại, không gửi dữ liệu người học đi đâu.
